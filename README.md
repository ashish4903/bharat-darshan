# Bharat Darshan

A free, open-data travel guide to India, state by state: places to visit, food to try and practical information.

> Work in progress. The first release covers five pilot states: Maharashtra, Goa, Rajasthan, Kerala and Delhi.

## Development

Requires Node.js 20 or newer.

```bash
npm ci
npm run dev     # local dev server
npm run check   # lint, formatting, tests with coverage, production build
```
